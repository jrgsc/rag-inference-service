# RAG Inference Service

A Node.js API gateway in front of a Python FastAPI service that does retrieval augmentd generation (RAG) over a small dataset, using the Claude API.

## Structure

- `node-gateway/` — Express gateway (auth, rate limiting, caching, routes requests to the Python service)
- `python-service/` — FastAPI service (embeddings, retrieval, Claude calls)
- `frontend/` — small React + Vite UI, just an input box hitting the gateway
- `docker-compose.yml` — spins up the whole stack (frontend, gateway, Python service, Redis) locally

## Status

RAG pipeline (chunk > embed > retrieve > answer) is done. Gateway now proxies
`/query` to the Python service with API key auth, ratelimiting, and Redis
response caching.

## dataset

The RAG dataset isn't included in this repo (it's personal/work docs, gitignored
under `python-service/dataset/`). To run this end-to-end yourself, drop your own
markdown docs in there and point the service at them (`DATASET_DIR` env var).

Embeds are generated with [Voyage AI](https://www.voyageai.com/), retrieval
runs through a local [Chroma](https://www.trychroma.com/) index, and answers
are generated by Claude.

## Local dev

```
cp .env.example .env
# fill in ANTHROPIC_API_KEY, VOYAGE_API_KEY, and GATEWAY_API_KEY (any random string)
docker compose up --build
```

This starts up everything, the frontend http://localhost:5173, the gateway http://localhost:3000, plus the Python service and Redis.

Build the index once (from inside the python-service container or a local venv):

```
python -m app.ingest
```

From there just open http://localhost:5173 and ask something. Or call the gateway directly:

```
curl -X POST http://localhost:3000/query \
  -H "Content-Type: application/json" \
  -H "x-api-key: <your GATEWAY_API_KEY>" \
  -d "{\"question\": \"...\"}"
```

Rate limit is 20 requests/min per gateway instance. Identical questions are cached in Redis for an hour.

Gateway health check: http://localhost:3000/health
Python service health check: http://localhost:8000/health

## Frontend

just a simple page allowing you to type a question, get an answer with sources. Talks to the
gateway, not the Python service directly. Comes up automatically with
`docker compose up`, but if you want to run it outside Docker:

```
cd frontend
cp .env.example .env.local
# set VITE_GATEWAY_API_KEY to the same value as GATEWAY_API_KEY
npm install
npm run dev
```

either way it proxies `/api/*` to the gateway, so no CORS setup needed.

## Lint & tests

Gateway (from `node-gateway/`):

```
npm run lint
npm test
```

Python service (from `python-service/`, with the venv active or via `.venv/Scripts/`):

```
pip install -e ".[dev]"
ruff check .
pytest
```
